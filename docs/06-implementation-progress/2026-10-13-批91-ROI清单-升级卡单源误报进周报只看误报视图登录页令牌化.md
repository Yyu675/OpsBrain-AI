## 四、灰度纪律对账

灰度 Day2：本批全部为**旁路/展示层/增量列/查询参数**——零状态机变更、零新依赖、零推送量变化（升级卡仅换渲染格式）。V18 是 `ADD COLUMN IF NOT EXISTS ... DEFAULT 0` 增量，快照器 upsert 列清单同步，旧行默认 0 且周报对「列缺席」刻意不渲染（默认 0 与缺席语义不同：0=真没人标过，缺席=数据未开始采集）。
