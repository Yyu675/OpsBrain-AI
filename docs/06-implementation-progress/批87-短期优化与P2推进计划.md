### **优化 1：Actuator 监控增强**（优先级：高，成本：30分钟）
**现状**：
- 已启用 `/actuator/prometheus` 端点
- 仅暴露 health, prometheus, info

**方案**：
```yaml
# application.yml
management:
  endpoints:
    web:
      exposure:
        include: health,prometheus,info,metrics,httptrace  # 增加 metrics
  metrics:
    tags:
      application: ${spring.application.name}
      env: ${spring.profiles.active}
    export:
      prometheus:
        enabled: true
```

**收益**：
- 实时监控 HTTP 请求延迟（P50/P95/P99）
- JVM 堆内存/GC 监控
- 数据库连接池状态

### **优化 3：Redis 缓存监控**（优先级：中，成本：1小时）
**现状**：
- 语义缓存命中率未监控
- 不知道哪些查询被缓存，哪些未命中

**方案**：
```java
@Component
public class CacheMetrics {
    private final MeterRegistry registry;
    
    public void recordCacheHit(String cacheName) {
        registry.counter("cache.hits", "cache", cacheName).increment();
    }
    
    public void recordCacheMiss(String cacheName) {
        registry.counter("cache.misses", "cache", cacheName).increment();
    }
}

// 在 SemanticCacheService 中埋点
if (cached != null) {
    cacheMetrics.recordCacheHit("semantic");
} else {
    cacheMetrics.recordCacheMiss("semantic");
}
```

**Prometheus 查询**：
```promql
# 缓存命中率
rate(cache_hits_total{cache="semantic"}[5m]) 
/ 
(rate(cache_hits_total{cache="semantic"}[5m]) + rate(cache_misses_total{cache="semantic"}[5m]))
```

### **优化 4：API 响应时间预算**（优先级：中，成本：30分钟）
**现状**：
- 技术架构设计中定义了 P99 < 2s 目标
- 未实施监控和告警

**方案**：
```java
@Aspect
@Component
public class ApiLatencyAspect {
    private final MeterRegistry registry;
    
    @Around("@annotation(org.springframework.web.bind.annotation.PostMapping)")
    public Object measureLatency(ProceedingJoinPoint pjp) throws Throwable {
        Timer.Sample sample = Timer.start(registry);
        try {
            return pjp.proceed();
        } finally {
            sample.stop(Timer.builder("api.latency")
                .tag("method", pjp.getSignature().getName())
                .register(registry));
        }
    }
}
```

**Prometheus 告警规则**：
```yaml
# P99 延迟 > 2s 告警
- alert: ApiLatencyHigh
  expr: histogram_quantile(0.99, rate(api_latency_seconds_bucket[5m])) > 2
  for: 5m
  annotations:
    summary: "API P99 延迟超过 2s"
```
