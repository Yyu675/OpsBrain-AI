## 四、发现的隐藏问题

### 4.1 Knip 误报（已排查）
以下依赖被 Knip 标记为"未使用"，但实际是**懒加载导致的误报**：
- `@wangeditor/editor`：被 `KnowledgeRichEditor.vue` 异步引用 ✅
- `@wangeditor/editor-for-vue`：富文本编辑器 Vue 3 适配层 ✅

### 4.2 CodeMirror 警告
```
[INEFFECTIVE_DYNAMIC_IMPORT] @codemirror/lang-markdown is dynamically 
imported by codemirror-language-data-slim.ts but also statically imported 
by md-editor-v3, dynamic import will not move module into another chunk.
```

**解释**：
- `md-editor-v3` 静态引入了 Markdown 语言包
- 我们的精简配置也动态引入了它
- Rollup 无法将其独立成 chunk，但不影响功能

**影响**：无影响，Markdown 包会合并到主包

**响应**：
✅ **已理解并记录**

**后续数据库变更流程**：
1. 所有表结构变更、索引调整、数据修复直接编辑 `V1__baseline.sql`
2. 不再创建 `V2__xxx.sql`、`V3__xxx.sql` 等新文件
3. 变更后需要：
   - 删除 Flyway 历史表：`DELETE FROM flyway_schema_history WHERE version > '1';`
   - 或重建数据库：`DROP DATABASE opsbrain; CREATE DATABASE opsbrain;`
   - 重新运行迁移：`mvn flyway:migrate` 或启动应用

**风险提示**：
- ⚠️ 生产环境已运行 V1 后，修改 V1 会导致 checksum 不匹配
- 建议：开发环境使用此方式，生产环境仍使用增量迁移
