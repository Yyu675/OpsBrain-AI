### 1.2 值域维度开张——修正批86 的过宽断言

批86 进度档曾断言「OpenAPI 产不出枚举值域」——**该断言只对 String 字段成立**。实测：**Java enum 字段 springdoc 会产 const enum**，orval 生成
`export const RiskPolicyApprovalMode = { NONE:'NONE', SINGLE:'SINGLE', DUAL:'DUAL } as const` 与手写 `type ApprovalMode = 'NONE'|'SINGLE'|'DUAL'` 逐字同构。
升维断言（双向 `Exclude`，后端加枚举值/手写多值 → 编译期点名）：

```ts
export type ApprovalMode_GenOnly  = AssertDriftFree<Exclude<GenRiskPolicyApprovalMode, ApprovalMode>>
export type ApprovalMode_HandOnly = AssertDriftFree<Exclude<ApprovalMode, GenRiskPolicyApprovalMode>>
```

**第二轮对账 56 条断言全绿零漂移**（对比首轮 10 红全修）——手写类型这轮维护良好不是没用：闸的价值在下次契约变更时先红。RiskLevel 无孪生（DTO 侧字段是 String）如实挂账。
