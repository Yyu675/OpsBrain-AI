### 3. chartTheme canvas 归一路径补测（R1 五件，暗色目检自动化兜底）

批92 的 6 例只护 jsdom 降级路径；真浏览器的归一路径此前零自动化。
批93 用 **spy 假 canvas**（`patchCanvas` 替 `HTMLCanvasElement.prototype.getContext`，
模拟 Chrome 语义：`'#000'`→`'#000000'` 规范化、未登记颜色赋值被忽略、hex→RGBA 像素）
补 5 例：归一 rgb / 半透明 rgba 三位小数 / 令牌空早退 / **非法色回落** / 主题版本 MutationObserver 递增。

**先写失败用例再修的真 bug**：旧实现 `if (c.fillStyle === '#000')` 判非法色——
Chrome/Firefox 把哨兵 `#000` **序列化成 `#000000`**，比较恒 false → 非法色混过检查，
`getImageData` 读出 `rgb(0, 0, 0)` **黑块喂给 ECharts**（暗色下一片糊的来源之一）。
修法：**读回值 vs 读回值**（`sentinel` 与 `applied` 都取浏览器序列化后的值）+ `isBlackLike`
豁免「令牌值恰为黑色写法」的误杀（`#000/#000000/black/rgb(0,0,0)` 四种常见写法）。
6→**11 例**全绿。

### 4. Embedding 配额探针销账批91 台账 §五欠账（R0 四件）

**欠账原文**（批91 台账§五）：上游 embedding 免费额度耗尽（`AllocationQuota.FreeTierOnly`），
REAL 模式 `mvn verify` 启动被 `RealModeStartupGuard` 拒——当时只能切 MOCK 绕行，
「配额恢复后补 REAL 验证」挂账。

**探针实证**（2026-10-13 17:0x，不启 Spring、`.env` 直连）：
```
POST https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings  (model: qwen3.7-text-embedding)
→ HTTP 400
{"error":{"message":"Free quota exhausted. To continue accessing the model on a paid
basis, please add funds or disable the \"use free tier only\" mode in the management
console.","type":"AllocationQuota.FreeTierOnly","param":null,
"code":"AllocationQuota.FreeTierOnly"},"id":"481cbb29-…","request_id":"481cbb29-…"}
```
**结论：配额仍枯竭（外部额度问题，非本仓缺陷）**；REAL `mvn verify` 依旧被上游卡，
本批 `AI_MODE=MOCK` 跑（1884 基线口径不变）。

**顺手收口（欠账的「可运维性」半边）**：`RealModeStartupGuard` 把配额耗尽从
「渠道不可达——检查 base-url/api-key/model」里**分类出来**——旧口径会把值班人往
「改配置」的错方向指（配置根本没错）。新增 `isQuotaExhausted`（沿 cause 链 ≤8 层拼
message，词面 `quota/free tier/insufficient_quota/欠费/余额不足` 大小写不敏感匹配，
词面刻意收窄防误报），报「充值/关免费额度档，配置无误，无需改 base-url/api-key/model」；
**硬闸照旧拒启**（REAL 模式 embedding 不通就是不能起），只改话术方向。
双向断言 2 例（配额→新口径+保留上游回执原文；网络故障→旧口径不反向误伤），
`RealModeStartupGuardPlaceholderTest` 4→**6 例**。
