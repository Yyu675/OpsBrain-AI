### 2.4 知识库详情页（KnowledgeDetail.vue）

#### 问题

| 级别 | 行号 | 问题 |
| :---: | :---: | :--- |
| P0 | 46-70, store 146-161 | `loadDetail`/`marked`/相关文章均无请求序号，快速切文档会串数据 |
| P0 | 218-246 | 废弃后只有 5 秒 Undo，过后无法恢复发布状态 |
| P1 | 53-64 | DOMPurify 白名单不强制 `rel="noopener noreferrer"`，`target=_blank` 有 tabnabbing 风险 |
| P1 | 53 | 启发式判断 Markdown vs HTML（`!raw.trim().startsWith('<')`）会误判 |
| P1 | 125, 137 | 用 `document.querySelector('.article-content')` 全局选择，应用 ref |
| P1 | 46-70 | `watch` 异步 `marked()` 无取消，切文档时旧文档的 marked resolve 可能写进新文档 |
| P2 | 441-447 | `indexStatus === 'FAILED'` 只有 title「向量化失败」，`indexError`/`retryIndexing` 都没接 |
| P2 | 489-496 | TOC 用 `href="javascript:void(0)"`，辅助技术不友好 |

#### 优化设计

1. **请求竞态修复**：`loadDetail` 加请求序号（仿 `loadList` 的 `listRequestSequence`）
2. **废弃恢复**：已废弃文档提供常驻「恢复发布」按钮，不只靠 5 秒 Undo
3. **Markdown 安全增强**：抽 `safeMarkdown()` 工具函数
   ```typescript
   // utils/safeMarkdown.ts
   export function safeMarkdown(raw: string): string {
     const isMarkdown = !raw.trim().startsWith('<')
     const html = isMarkdown ? marked.parse(raw) : raw
     return DOMPurify.sanitize(html, {
       ALLOWED_TAGS: [...],
       ALLOWED_ATTR: ['href', 'target', 'rel', 'class'],
       ADD_ATTR: ['rel'],
       // 强制给 target=_blank 的 a 标签补 rel
       // 通过 afterSanitizeAttributes hook
     })
   }
   ```
4. **全局选择器替换**：`article-content` 改用 `ref`
5. **向量化失败展示**：展示 `indexError`，提供「重试向量化」按钮
6. **TOC 无障碍**：`href="javascript:void(0)"` 改为 `<button>`

4. **大纲解析优化**：防抖到 1000ms，且只在内容变化超过阈值时触发
5. **离开保护统一**：统一用 `useDirtyGuard`，`handleBack` 调用 `confirmLeave()`

### 3.3 安全基线统一

```typescript
// utils/safeMarkdown.ts — 全局唯一 Markdown 渲染入口
import { marked } from 'marked'
import DOMPurify from 'dompurify'

marked.setOptions({ breaks: true, gfm: true })

const ALLOWED_TAGS = [
  'p', 'br', 'strong', 'em', 'del', 'code', 'pre', 'blockquote',
  'ul', 'ol', 'li', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
  'a', 'table', 'thead', 'tbody', 'tr', 'th', 'td', 'hr', 'span',
  'img', 'div', 'figure', 'figcaption'
]

const ALLOWED_ATTR = ['href', 'target', 'rel', 'class', 'src', 'alt']

// DOMPurify hook: 给所有 target=_blank 的 a 标签强制补 rel
DOMPurify.addHook('afterSanitizeAttributes', (node) => {
  if (node.tagName === 'A' && node.getAttribute('target') === '_blank') {
    node.setAttribute('rel', 'noopener noreferrer')
  }
})

const renderCache = new Map<string, string>()

export function safeMarkdown(raw: string, cacheKey?: string): string {
  if (!raw) return ''
  const key = cacheKey ?? raw
  if (renderCache.has(key)) return renderCache.get(key)!

  const isMarkdown = !raw.trim().startsWith('<')
  const html = isMarkdown ? marked.parse(raw) as string : raw
  const safe = DOMPurify.sanitize(html, {
    ALLOWED_TAGS,
    ALLOWED_ATTR,
    ADD_ATTR: ['rel'],
  })

  if (renderCache.size < 200) renderCache.set(key, safe)
  return safe
}
```
