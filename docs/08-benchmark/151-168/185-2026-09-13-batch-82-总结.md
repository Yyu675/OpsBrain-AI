### 2.4 Flyway Checksum 助手脚本（报告 184）

**文件**：`tools/deploy/flyway_checksum_helper.sh`（200 行）

**功能**：
1. **自动计算本地 checksum**：使用 `cksum` 模拟 Flyway CRC32 算法
2. **查询数据库 checksum**：从 `flyway_schema_history` 表读取版本 1 记录
3. **对比与诊断**：一致 → 提示无需修复；不一致 → 生成修复 SQL
4. **生成修复 SQL**：自动生成带时间戳的备份表 + UPDATE 语句
5. **交互式执行**：显示对比结果，询问是否立即更新数据库

**使用方式**：
```bash
# 基本用法（自动检测 V1__baseline.sql）
./tools/deploy/flyway_checksum_helper.sh

# 非交互模式（仅计算，不更新）
INTERACTIVE=false ./tools/deploy/flyway_checksum_helper.sh

# 自定义数据库容器名
DB_CONTAINER=my-postgres-1 ./tools/deploy/flyway_checksum_helper.sh
```

**安全保障**：
- ✅ 自动备份 `flyway_schema_history` 表（带时间戳）
- ✅ 交互式确认（防止误操作）
- ✅ 彩色日志输出（INFO/WARN/ERROR 区分）
- ✅ 错误处理（文件不存在/容器未运行）

### 6.2 新策略的风险

⚠️ **Flyway checksum 变更频繁**
- 每次追加索引/表/列，V1 文件 checksum 都会变化
- 生产环境需手动修复 checksum（已有助手脚本缓解）

⚠️ **回滚困难**
- V1 单文件无法逐批次回滚（需整库重建）
- 建议：每批次变更前备份数据库

⚠️ **多人协作风险**
- V1 文件易冲突（当前单人开发暂无此问题）
- 若未来扩展团队，需评估恢复多文件迁移策略
