## 四、本批设计原则沉淀

1. **付费决策权归属**:任何消耗真实成本的 LLM 调用必须由用户显式动作触发——系统可提示(空态按钮),不可代答;
2. **工作产物必须落盘**:AI 生成≠会发布,草稿(复盘沉淀/AI 分析)一律存档复用,关页不丢、重开不烧;
3. **展示器职责单一**:状态变量只服务一个 UI 消费方——分析卡显示分析,回复框显示草稿,复用状态=相互污染(方案 B 教训);
4. **低质量结论不占位**:自动链路产出达不到展示门槛的(证据不足),走通知不进分析表,不给用户「AI 已尽力」的假象。
