## 四、残留与挂账（诚实口径）

1. **取消标记的极端窗口**:模型 HTTP 流挂死（无 complete/error 回调）时标记要等 HTTP 客户端自身超时（60s/120s）才随 onError 清理——LangChain4j 客户端超时兜底,无永久泄漏路径,但窗口内 isCancelled 恒真（该 traceId 已死,无消费者,无实际影响）。
2. **SSE 已生成 token 的成本**:断连只能止损「后续」,已向模型发出的请求无法撤回——这是 OpenAI 兼容协议的普遍边界,非本系统缺陷。
3. **语义缓存写入**（onCompleteResponse 内）在断连时仍会执行:已花掉的 token 换一份缓存供下次命中,是把沉没成本变废为宝,刻意保留。
4. 版本切换器用原生 select:功能完整,样式朴素;Element Plus 化留待 UI 统一批次。
