### 1.3 环境变量审计

**扫描命令**：
```bash
grep -rn "import\.meta\.env\.VITE_" src/ --include="*.ts" --include="*.vue" | grep -v "__tests__"
```

**结果**：3 处

**详情**：
1. **BASE_URL**（api.ts:8）：
   ```typescript
   export const BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8088/ai'
   ```
   - 正常使用，有本地开发回落

2. **VITE_SKIP_AUTH**（router/index.ts:312）：
   ```typescript
   if (import.meta.env.VITE_SKIP_AUTH === '1') {
   ```
   - 开发期跳过鉴权开关，**生产需确保未设置**

3. **VITE_DISABLE_AUTH_REDIRECT**（http.ts:389）：
   ```typescript
   if (res.status === 401 && import.meta.env.VITE_DISABLE_AUTH_REDIRECT !== '1') {
   ```
   - 401 重定向开关（批 75 P1-5 改为 opt-out），**生产需确保未设置**

**风险评估**：
- 环境变量仅 3 处，可控
- 两个开关（SKIP_AUTH / DISABLE_AUTH_REDIRECT）若在生产误配会绕过鉴权 → **需部署检查清单**

**建议**：
- 生产 `.env.production` 明确注释：
  ```bash
  # ⚠️ 以下开关仅供开发，生产禁止设置
  # VITE_SKIP_AUTH=1
  # VITE_DISABLE_AUTH_REDIRECT=1
  ```
- CI 部署脚本加检查：
  ```bash
  if grep -q "VITE_SKIP_AUTH=1" .env.production; then
    echo "❌ 生产环境不得设置 VITE_SKIP_AUTH" && exit 1
  fi
  ```
