## 二、本批拔出的两颗地雷（欠账的真正成因）

1. **LLM 端到端层自开工起就是空壳**：`llmEndToEndEvaluation()` 只断言
   「数据集 50 正+50 负的规模」，真实 SSE 链路+断言全是 TODO 注释。
   「EVAL_LLM 窗口」欠账（4-1.3/4-1.4/4-1.5）一直被挡在外部条件的说法
   只讲对了一半——**窗的里面是空的**。
2. **`@TestPropertySource` 把 `devops.ai.mode` 钉死 MOCK**：就算有人带着真
   key 开 EVAL_LLM=true，跑的也是 Mock Bean，只会产出无语义假账且毫无提示。
   空格键+钉死键=假账制造机的完美形态。
