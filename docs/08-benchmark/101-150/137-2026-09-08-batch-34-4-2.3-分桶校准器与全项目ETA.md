## 一、4-2.3 落地：`BucketCalibrator`

| 面 | 内容 |
| --- | --- |
| 语义 | 置信度后验修正：某 bin 的历史真实正确率 = 该 bin 自报置信度的修正值（D-06 方案 A；温度缩放需 logits 仓库未暴露，已在案） |
| 红线① | 空校准集 → **恒等映射**（没数据不许假装会校准，报告口径须写「未校准」） |
| 红线② | 空 bin 回退**全局正确率**（有据估计），不回退原值（无据）——未知区间不当已知 |
| 证据面 | `recalibrate` 产出可直接喂 `EceMetrics.ece`，4-2.4 前后对比=同一公式对称调用 |
| 钉测 | 7 例（拉低/抬升/空 bin 回退/恒等/越界抛/**校准后 ECE 必降构造证明**/recalibrate 保 correct）；零 JDK 环境，仲裁权交 CI 后端腿 |

**至此 S4-2(4-2.1~4-2.5）代码侧清零**，剩余全部是「真窗数据流入」而非「代码待写」：
置信度采集通道（评测回调一寸）→ 喂对 → ECE 前后对比入报告 → ECE ≤ 0.15 验收核对。
