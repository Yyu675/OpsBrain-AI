## 二、设计纪律（与既有弹药互为表里）

1. **`tee` 不吞 rc**：GHA bash 默认 `-eo pipefail`，`node … | tee` 的劣化 rc=1
   原样传导——评论内容与门禁结论是同一份输出，不会出现「门禁红了、
   评论到绿」的两账。
2. **marker 幂等而非堆评论**：同一 PR 反复 push 更新同一条评论——
   对比是「最近一次状态」的审计语义，不是流水账。
3. **最小放权**：`pull-requests: write` 只开评论所需的权限面，
   `contents: read` 不动。
4. **首跑不误红反复被验证**：patch 期（报告 121 §三）与挂线期（run
   34203717807）两轮实证；建账由用户本地 EVAL_LLM 真窗完成（清单 §3）。
