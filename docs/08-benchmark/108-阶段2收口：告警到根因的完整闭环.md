## 二、主流数据链路全景（证据链全程追溯）

```
告警 → (入库+去重) → 自动建单 → (异步触发诊断)
        │
        ├─ 三方向取证: metrics / changes / logs
        │
        ├─ EvidenceAggregator 判定
        │     SUFFICIENT / WEAK / INSUFFICIENT
        │
        ├─ HypothesisGenerator（双轨）
        │     规则基线永远可用 / LLM 可插拔
        │     Top-3 假设 + evidence_ids
        │
        ├─ ConfidenceEngine 钳制
        │     [0.1, 0.95]；WEAK 硬帽 0.6；冲突 -0.10/条；证据不足 -0.20
        │
        ├─ 摘要 + 状态机落盘（V4 表）；
        │      回填工单 AI 分析区（2-1.5 落地）
        │
        └─ WebSocket 推送 + DingTalk 通知（2-1.6 落地）
                → 前端诊断页（历史和实时双重可见）
```

## 三、四态聚合判定规则（改判不回头）

| 成功 | 失败 | 无有效证据 | 判定 |
|---|---|---|---|
| ≥2 且 NOT FAILED | — | — | INSUFFICIENT（终止推理）|
| ≥1 且 FAILED == 1 | — | — | WEAK（上限 0.6）|
| — | ≥2 | — | INSUFFICIENT（终止推理）|
| NO_DATA 主导 | — | — | INSUFFICIENT（证据不足，不是「没看出」）|

*核心约束：FAILED ≥ 2 必终止；NO_DATA 导向引导不走出去。「证据不足」和「没看出」语义上不同——前者是证据层缺失，后者是诊断层缺失。两者混用会严重误判。*

## 四、证据回放三级数据点

| 表 | 主键/索引 | 关键约束 |
|---|---|---|
| `sys_diagnosis_session` | `alert_id`（UNIQUE）、`trace_id`（INDEX） | status（RUNNING/COMPLETED/REJECTED/FAILED）+ sufficiency |
| `sys_diagnosis_evidence` | `trace_id`（INDEX） | `content` 原 JSON 落库（不加工；回放应该看到当时长什么样） |
| `sys_diagnosis_hypothesis` | `session_trace_id`（INDEX） | `evidence_ids`（JSON：点开假设看证据的关联键）；`feedback`（覆盖式单值列） |
| `sys_knowledge_boost` | `chunk_id`（PRIMARY KEY） | helpful_count / wrong_count 单调递增计数器（对写明可） |

## 五、设计原则沉淀

| 原则 | 落地 | 为什么 |
|---|---|---|
| 异步有界线程池 | `ThreadPoolExecutor(4, 8, QUEUE=100)`；CallerRunsPolicy 弃用 | webhook 线程绝不背诊断负载 |
| 取证确定性编排 | 三方向指标 Collector 直接调用，不交模型规划 | 告警场景要求取证路径稳定可回放 |
| 置信度钳制 [0.1, 0.95] | 曲线斜加再向下烙印，保留人工复核的缝隙 | 机器自信不能直通到近满分 |
| 诊断失败不反噬 | 失败只影响 `ERROR` 状态迁移 | 告警/建单已脱离风险区，诊断延迟不上溯 |
| 同告警不重复触发诊断 | `alert_id` UNIQUE 索引 + ON CONFLICT DO NOTHING | 风暴期间同一故障源不会产生数十条并发诊断 |

## 九、诊断数据表不变性（复盘三处小事）

1. **「证据原样落库」**：V3 `sys_diagnosis_evidence` 的 `content` 列从不做字段提取——
   审计取值的是「当时长什么样」，不是被重排过的抽象层
2. **「单值列反馈最后为准」**：V5 `sys_diagnosis_hypothesis.feedback` 是覆盖式更新，
   重复反馈记录最新一次（不整为幂等日志）
3. **「计数器单调性」**：V6 `sys_knowledge_boost` helpful/wrong 单调递增，撤摘基本字段
   （幂等的写入保证，不是增量多）
