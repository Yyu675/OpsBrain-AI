## 三、推荐执行路径（三步走，每步都有可交付物）

```
第一步（本周可启动，不依赖任何拍板）——「闭环可见性」
  P1 Saga 前端（2-3 天）
  P2 可观测性（3-5 天）
  并行：P3 Flyway（2-3 天，卫生轨）
  → 交付：演示剧本 v1「5 分钟讲完 告警→建单→诊断→审批→补偿→审计」
  → Exit：/actuator/health 绿灯 + Saga 页面可操作

第二步（需 D1 拍板）——「真实执行器」（演示王牌）
  D1 选型：K8s（fabric8）+ 双轨验证（沙箱 FakeK8sClient 保 CI / 本机 kind 保演示 / mock 兜底）
  V1.2 只读执行器 queryPodStatus 走通治理全链路
  → 交付：演示剧本 v2「真实告警 → AI 诊断 → 白名单只读查询 → 审计留痕」
  → Exit：治理链路被第二个场景验证；面试可现场演示

第三步（V2.0）——「可信度与外部世界」
  评测集（3-5 天）→ 指标可对口径
  知识运营看板（2-3 天）
  工单双向接入 / SLS / 钉钉一键授权（按需选做）
  → 交付：演示剧本 v4「指标看板对口径 + 知识盲区闭环」
  → Exit：8 项成功指标全部有评测集支撑
```

**配套（随时）**：前端 5 个自愈占位路由实现前从导航摘除（防「空壳」观感，0.5 天）。
