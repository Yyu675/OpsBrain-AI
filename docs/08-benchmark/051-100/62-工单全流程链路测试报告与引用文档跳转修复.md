## 一、引用文档 / 相关文档修复

### 1.1 根因

| # | 问题 | 根因 |
|---|------|------|
| 1 | 相关文档「暂无相关文档」 | `loadRelatedDocs` 用「服务名 + 工单标题」整串查询知识库，mock 关键词为**整串包含匹配**，几乎命中不了任何文档 |
| 2 | 引用文档不显示、不能跳转 | `AnalysisCard` 的 citations 渲染为**纯文本** `<span>{{ cite }}</span>`（前端本来就只接收标题字符串，无 id、无 RouterLink） |

### 1.2 修复（前端增强，对真实后端同样生效）

| 文件 | 改动 |
|------|------|
| `useTicketAnalysis.ts` | 新增 `citationDocs` ref + `resolveCitations()`：对 citations 标题逐个 `fetchKnowledgeDocs({keyword, size:1})` 解析出 `{id, title}`（并发查询，单个失败仅该项降级纯文本）；**存档加载与实时生成两条路径均接入**；export 新增 `citationDocs` |
| `AnalysisCard.vue` | props 新增 `citationDocs?: Array<{id, title} \| null>`；引用区改为：命中 → `RouterLink` 跳 `/knowledge/{id}`（带箭头图标 + title 提示）；未命中 → 纯文本（保持现状） |
| `TicketTimeline.vue` | `TimelineAnalysis` 类型与传参透传 `citationDocs` |
| `TicketDetail.vue` | 解构 `citationDocs` 并传入 analysis 对象 |
| `mock server.js` | 知识库 keyword 改为**分词 OR 匹配**（模拟真实后端向量+关键词混合检索的宽松语义），「容器/K8s 支付服务 Pod 频繁重启」可命中 K-001/K-006 |
