## 三、S4-2 ECE 骨架规格(报告 117/123 挂账「ECE 实现待 LLM 真窗」的计算半部)

- **公式**:ECE = Σ_k (|B_k|/N)·|acc(B_k) − conf(B_k)|,等宽 bin(默认 10),1.0 归末 bin。
- **两条红线入 javadoc**:
  ① 空样本 → **NaN**——ECE 越低越好,空集报 0 = 把「没测过」报成「完美校准」的方向版假满分,
  落盘侧见 NaN 跳键(「留空拒伪造」的方向镜像);
  ② 置信度越出 [0,1] → **抛异常**——静默钳位会把上游单位错误藏成永恒的「100%/1 之争」。
- **同楼同构**:计算与数据源分层(对照 RetrievalRankMetrics 类注释),11 例确定性钉测常驻 CI
  (完美校准=0 / 双向极端=1 / 尺寸加权 / 分家边界 / 聚合三量 / 越界与非法 binCount 双抛)。
- **compare 预接**:`REVERSE` 方向词表加 `\bece\b|calibration`(比率径,阈 ±2pt);
  `\b` 边界经转台实证(pieceRate +89pt 不误判);转台三案:ece +3pt→✗ rc=1、-3pt→✓、撞名防护 ✓
  (转台两层壳已吸取批 31 教训:layers 嵌套 + current/baseline 角色 + 直取 NODE_RC 不被 grep 管道偷换)。
