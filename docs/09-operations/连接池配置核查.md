## 二、落器唯一件：生产 Hikari 块（appliction-prod.yml)

| 键 | 默认 | 理由 |
| --- | --- | --- |
| `maximum-pool-size` | 20 | replicas × pool ≤ 100 × 0.7；副本上限 3 不松紧 |
| `minimum-idle` | 5 | 冷启尖刺廉价缓冲，别置 0 值再重连 |
| `connection-timeout` | 20000 | 等不来的连接多等 10s 只押线程 |
| `max-lifetime` | 600000 | 显著 < 链路设备空闲断（LB 常见 10-30m)，自己先死好过被对端先杀 |
| `idle-timeout`/`keepalive` | 300000/240000 | keepalive < idle 是铁序；心跳廉价补偿 「读到已死未过期连接」 |

**五口径全进 env**——生产口径由部署方管，不埋在仓。

## 三、诊断口径保留

- 池耗尽三兄弟指标（`hikaricp.connections.active/idle/pending`）已可经

  dev 方言 10/2/30s 不变，那边是调查现场）。
