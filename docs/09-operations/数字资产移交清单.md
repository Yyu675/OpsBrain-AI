## 一、部署包验证（六步骤，首装/升级通用)

```bash
# 1. 栈起：硬件预算 commits app(2g/1.5/768m)
docker compose up -d
docker compose ps               # 全容器 healthy(HEALTHCHECK 在 Dockerfile)
# 2. 迁移触及:flyway_schema_history 版本连续 1..11 全 success
docker compose exec postgres psql -U devops -d devops_knowledge_db \
  -c "SELECT version,success FROM flyway_schema_history ORDER BY installed_rank DESC LIMIT 3"
# 3. 烟囱:三端点(ping 只活/health L2 只达结/probes 探针分离)
curl -sf http://localhost:8088/ai/api/v1/health/ping
curl -sf http://localhost:8088/ai/actuator/health/liveness
curl -sf http://localhost:8088/ai/actuator/health/readiness
# 4. 监控自证:Prometheus 抓 app job 上线(ups=1)
curl -sf "http://localhost:9090/api/v1/query?query=up{job='opsbrain'}"
# 5. 备份首演:backup.sh 出包 + manifest 三件互锁(SHA)——记录表在《部署运维手册》§演练
./scripts/backup.sh
# 6. 登录污染图:AUTH_SEED_PASSWORD 已改(废 admin123);L2 JWT 密钥不入 git 验证
```
