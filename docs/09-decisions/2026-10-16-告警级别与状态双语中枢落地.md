---

## 一、方案落地明细

1. **告警级别中文标签化映射 (`formatLevel`)**：
   - `P0` / `DISASTER` → `P0 灾难级（Disaster）`
   - `P1` / `HIGH` → `P1 严重级（High）`
   - `P2` / `AVERAGE` → `P2 一般严重（Average）`
   - `P3` / `WARNING` → `P3 警告级（Warning）`
   - `P4` / `INFO` → `P4 提示级（Info）`
   - 其他未知输入优雅原样回退，不抛出异常。
2. **卡片结构呈现**：
   - 触发通知与恢复通知均在当前状态（`告警中（PROBLEM）` / `监控恢复（OK）`）后紧跟 `- **告警等级**：P2 一般严重（Average）`；
   - 标题结构保持与历史检索兼容性，正文前置直观中文，彻底消除英文认知摩擦。
3. **自动化测试契约**：
   - 在 `AlertNotifyTemplateTest.java` 企业样本单测中同步增加触发与恢复双侧等级断言。
