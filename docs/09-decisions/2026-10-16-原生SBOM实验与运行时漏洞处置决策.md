# 批115：原生 SBOM 实验与运行时漏洞处置决策

## 决策：推进独立实验，不直接替换生产输入，不宣布安全修复

原生 Maven SBOM 能显著补足 pom 直接扫描漏掉的传递包，但**它与实际部署 JAR 不是同一清单**，且已真实检出大量 HIGH/CRITICAL。本批交付可复跑的输入/字节/门禁实验，保留原生产前端与 Secret 扫描，不擅自把新输入当生产放行，也不把实验 job 绿说成安全绿。

下一优先项：独立修补已核实且字节关联的传递漏洞，并处理 SBOM 与 Boot 打包边界；Spring 升级/回补/不可达性验证另作兼容性决策，不用扫描器的跨主线 FixedVersion 强制跳 Boot4，不添加忽略规则。

### 部署边界不能靠包数猜

- Maven 树中14个 variants 未进入打包库：Lombok，以及13个 Boot starter。不能把这些全当部署漏扫库，也不以此临时修改扫描豁免。
- SBOM 比树多4个坐标：`jakarta.activation-api:2.1.4`、`jakarta.xml.bind-api:4.0.4`、`spring-core:6.2.17`、`spring-jcl:6.2.17`。第二轮实际字节关联已证明这4个坐标均在Boot JAR内，且原runtime tree无对应路径；所以不能因“超出树基线”就算误报。尚未确定两个原生插件/有效模型表达差异的具体机制，不猜scope根因。
- 每个 Boot lib 的实际字节 SHA256 对照原生 SBOM 的组件 SHA256；同名不同字节绝不绑定。相同哈希若对应多个组件，必须进一步唯一绑定，否则列为未知，而不是随便选一个。未描述的 Boot 工具库显式保留，不靠文件名猜 GAV。
- 扫描包集目前核的是 GAV，SBOM/Boot核的是带 type/classifier 的组件与字节；不把这两层合并成“scanner已逐classifier检查”。

## 流程与失败语义

1. 保持批113的一次生产fs→同源派生→convert、默认HIGH/CRITICAL、前端/Secrets扫描不变。
2. 在后置独立审计runner中，先完成批114的冻结raw覆盖对照，再真实package，并显式执行固定`org.cyclonedx:cyclonedx-maven-plugin:2.9.1:makeBom`，schema1.6、JSON、compile/runtime纳入，provided/test/system排除，生成物在/tmp。
3. 实验JAR构建使用`-DskipTests`，并非代替集成测试：原CI仍全量执行后端、真实浏览器和真库集成。Maven失败保原码，零退出但未产出新SBOM也失败，不用陈旧文件。
4. 固定同版本Trivy0.70.0，只对原生SBOM扫描一次，留含未修项的原始JSON，再按官方Status=fixed派生，由convert判原始门禁码。实验0/1分别记录；工具异常码>1、缺报告/坏JSON、发现不一致或吞原码均报红。
5. helper核对树→SBOM variants、SBOM→扫描GAV、SBOM→实际Boot内嵌库SHA256；原生门禁结果必须与同源候选发现完全一致。全部输入含Boot JAR自身SHA及checkout SHA关联。
6. 合法差异与漏洞形成warning、`status=incomplete`、`native_gate_rc=1`等明确风险状态，**不是生产放行**。原始SBOM、报告、原码、政策输入/manifest、实验结果和日志always上传；不上传庞大的Boot二进制到Git。
7. 完整实验过大时，Check注解仅发带校验的紧凑分片（省略完整库列表），说明完整字节证据仍在artifact。不再依赖约4KB会被截断的单条JSON。

## 方案利弊与是否推进

| 方案 | 收益 | 风险/成本 | 决定 |
|---|---|---|---|
| 继续只扫pom | 不增加构建成本 | 实证只读32个外部Java包、遗漏传递风险 | 不能据此判安全 |
| 直接用原生runtime SBOM替换全部生产扫描 | 能读297 GAV，发现真实漏项 | 漏Boot新增工具库；与实际打包范围不同；不能因此丢前端/Secrets | **当前不选** |
| 独立SBOM+实际打包字节对照 | 得到可验证差异及风险，不污染原生产扫描 | 增加一次package/原生插件/DB扫描成本；安全修补尚未完成 | **本批采用** |
| 按实际Boot lib构建/补全可追溯SBOM，再与现有其他扫描面组合 | 更贴近真正部署范围 | 需核身份/哈希/平台组件、处理额外工具库并真实回归 | 后续在证据基础上推进，不用文件名猜坐标 |
