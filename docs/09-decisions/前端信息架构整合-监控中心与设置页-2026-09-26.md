# 前端信息架构整合：监控中心 + 设置页 + 数据概览瘦身（2026-09-26）

## 背景与决策

用户提出三项调整，方案经确认后实施（UX 改动三方案比选，均为推荐项中选）：

| # | 需求 | 采用方案 | 落选方案 |
| - | - | - | - |
| 1 | 实时监控 + 趋势分析合并 | **单页分区仪表盘**（监控中心：上半区实时卡片，下半区趋势探索器） | 页内双标签（另一半默认不可见，看板感弱） |
| 2 | 治理页迁入设置页 | **配置类进设置标签**；审批中心/自愈中心是处置队列，升为顶栏入口（限 admin） | 治理全进设置（审批要多点一次）；最小迁移（隐藏页继续隐藏） |
| 3 | 数据概览疑似打不开 + 是否保留 | **保留但瘦身**：定位「值班首屏」，与效能大盘重复的闭环度量/诊断区迁往效能大盘 | 两盘合并（页面过长、L1/L3 受众混排）；原样保留（重叠照旧漂移） |

## 数据概览「无法打开」核查结论

页面本身无故障：typecheck 通过，admin 登录态实测六个后端接口全部 200、
页面渲染完整、控制台零错误。唯一复现的「打不开」路径是**未登录访问被
路由守卫拦截**（弹「请先登录」，选留下则原地不动）——设计内行为。
附带发现并修复命名不一致：导航叫「数据概览」，路由标题却是「运维大屏」
（已统一为「数据概览」）。

## 实施账

### 监控中心（/monitoring）

- 新增 `components/monitoring/TrendExplorer.vue`：原 Trends.vue 整页内容抽为组件
  （指标目录、五档时间范围、实例线图、区间统计），URL 筛选（range/metric）保留。
- `Monitoring.vue` 改标题「监控中心」，下半区嵌入 TrendExplorer；
  两处「去接入管理」出口改指 `/settings?tab=integrations`。
- `/trends` 路由删除，重定向到 `/monitoring` 并**保留 query**
  （旧分享链接 `?range=7d&metric=...` 落点语义不变）。
- `Trends.test.ts` 迁移为 `TrendExplorer.test.ts`（断言不变，组件换名）；
  `Monitoring.test.ts` 四处 mount 加 TrendExplorer 桩 + 新增「合并页包含趋势区」断言。

### 设置页（/settings）

- 新增 `views/Settings.vue`：左侧标签轨（窄屏变顶部横滚条），`?tab=` 进 URL，
  标签按角色过滤（admin：常规/模型渠道/自动化策略/动作白名单/风险等级/接入管理/
  审计日志；其余角色：常规/接入管理），直链无权限标签静默回退「常规」。
  不用 keep-alive——接入管理等页挂了 30s 轮询，保活会让隐藏标签后台打接口。
- 新增 `components/settings/GeneralSettingsPanel.vue`：承接原 SettingsDialog
  的「通知/显示/安全」三节（弹窗语义原样，外观仍即时生效）。
- 删除 `SettingsDialog.vue`；顶栏「系统设置」改为跳转 /settings；
  通知关闭态的「前往开启」同步改跳。
- 六个旧路由重定向到对应标签：/model-channels、/automation/policies、
  /automation/action-allowlist、/automation/risk-levels、/integrations、
  /governance/audit-logs。三个已实现但导航隐藏的配置页（自动化策略/动作白名单/
  风险等级）借机启用。
- 异步标签包装器**必须命名**（与目标组件同名）：VTU 按组件名匹配 stubs，
  匿名包装器会让测试桩失效、真实面板的 API 依赖被连带加载。
  （教训记录：vi.mock 整个 .vue 模块会被 VTU 的 createDefaultStub 持续探测
  命名空间上的 `__isTeleport/__isKeepAlive/__v_isVNode/name` 等内部字段，
  桩不胜桩；按名 stubs 才是正路。）
- `theme-tokens.contract.test.ts` 的硬编码白豁免条目随滑块样式迁入
  GeneralSettingsPanel.vue。

### 导航（navigation.ts + AppNavbar.vue）

- 撤销「治理」下拉与 `group` 分组机制；导航 = 扁平的日常作业面。
- 审批中心、自愈中心进顶栏，均限 admin。**自愈中心此前对全员可见、
  点进去却是 403**（路由 meta.roles 限 admin，导航项没标）——导航与路由的
  角色错配在本次对齐修复。
- activeKey 新增 /approvals、/self-healing 映射；/settings 不高亮任何顶栏项
  （回落「首页」会误导）。

### 数据概览瘦身（Dashboard.vue / Effectiveness.vue）

- Dashboard 移除：闭环度量（MTTA/MTTM/MTTR/跳过验证率/阶段完成率）、
  诊断区（会话 KPI/充分性/方向明细表/校准/AI 反馈/诊断量趋势）。
  保留：AI 调用 KPI、SLA 风险清单、实时告警流、模型分布、成本与命中率趋势、
  工单趋势、根因分类分布（效能大盘无此读数，属业务向）。
- Effectiveness 承接：闭环阶段漏斗条、诊断会话与 AI 效果区
  （会话/完成/均耗时/均价 + 根因准确率/反馈 + ECE/经验正确率 + 诊断量趋势图），
  数据全部来自已有的 closure/board 查询 + 复用 useAiAnalysisStatsQuery。
- `dashboard.query.ts` 删除失效的 useClosureMetricsQuery / useDiagnosisBoardQuery
  （消费方已迁走；类型 re-export 的 @public knip 存证行保留）。
