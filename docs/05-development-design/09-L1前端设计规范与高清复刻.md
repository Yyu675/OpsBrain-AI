## 二、统一设计规范（Design Tokens）

设计稿与现有 `src/assets/styles/variables.scss` **完全同源**（色板/字号/行高/字重/圆角/间距/阴影均已对齐），无需改动变量；本规范为"冻结"而非"新建"。

| 维度 | 规范值 | 现状 |
| :--- | :--- | :---: |
| 品牌主色 | `--color-primary: #1B4F9C` / `-light: #2A6BC6` / `-lighter: #E8F0FC` / `-dark: #0E2F5A` | ✅ variables.scss |
| 背景 | `--color-bg: #F5F7FA`，卡片白 `--color-surface: #FFFFFF` | ✅ |
| 文字 | 主 `#111827` / 次 `#4B5563` / 弱 `#9CA3AF` | ✅ |
| 状态色 | 成功 `#16A34A` / 警告 `#D97706` / 错误 `#DC2626` / 信息=primary-light | ✅ |
| 字体 | `--font-body` = Inter + PingFang SC + Microsoft YaHei；展示标题 `--font-display`；代码 `--font-mono` | ✅ |
| 圆角 | sm 4 / md 8 / lg 12 / full 9999 | ✅ |
| 容器 | 页面内容区 `max-width: 1280px`（对齐设计稿 `max-w-7xl`），左右 `padding: 24px` | ✅ |
| 图标 | **lucide-vue-next**（设计稿用 lucide，命名一一对应） | ✅ |
| 图表 | **ECharts@6**（项目已有；设计稿用 Chart.js，复刻时为视觉等效实现：主色 `#1B4F9C` 渐隐、环形图 cutout 70%、横向条形、虚线次轴等） | ✅ devDeps |
| 阴影 | `--shadow-sm/md/lg`，卡片 hover 上浮 2px（`translateY(-2px)` + `shadow-lg`） | ✅ |
| 徽标（badge） | 圆角 full、`font-size: 12px`（--text-xs）、内边距 `2-4px × 8-12px` | 各页 scoped 内实现 |

**页面通用结构（复刻基准线）**：
1. **Page Header**：白底 `border-bottom`，左标题（`--text-2xl` bold 或 `devops-h3`）+ 副标题（caption），右主按钮（primary 实心）。
2. **搜索栏**：设计稿知识库页为「左侧 `3px` 主色竖条」+ 圆角输入框，placeholder 中文；列表页筛选栏为 `bg` 底色圆角控件。
3. **卡片**：白底 `1px border-light` + `radius-lg` + `shadow-sm`；分组卡片间距 `16-24px`。
4. **表格**：`thead` 用 `--color-bg-sunken`，`--text-xs` uppercase caption 表头；行 hover 用 `--color-primary-lighter`；编号列 `font-mono`。
5. **空/载/错态**：统一 `EmptyState` 组件；加载失败给「重试」；详情页三态（loading/notFound/error）沿用 6.18 契约。
6. **分页**：设计稿两种——知识库页中央数字按钮（34×34），工单页「显示 X-Y 共 N 条」+ 数字按钮。

## 四、铁律（复刻时不破坏）

1. **数据真实**：编号、分类计数、KPI、状态等一律来自后端；设计稿中的示例数字（OPS-2024-0891、194 条、92% 等）**禁止伪造**；无法提供的字段宁可不渲染或标「预览数据」。
2. **写操作继续落库**：工单/知识库所有写方法（乐观更新 + 回滚快照）不得因样式改版而退化。
3. **三态与兜底**：详情页 loading/notFound/error 三态、EmptyState、DOMPurify 白名单、版本冲突 40009 提示等既有契约保持不变。
4. **不改共享层**：本轮冻结决策下禁止改 `variables.scss`、`AppNavbar.vue`、`router/index.ts`（路由已就绪）、stores 的 API 契约；如需新增小工具样式，只在页面 scoped 或新建页面级公共组件内完成。
5. **构建验证**：每轮交付后 `npm run build`（vue-tsc + vite）必须通过。
